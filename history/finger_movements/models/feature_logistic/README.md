# Archived Feature Logistic Model

This model replaced AdamW training with L2-regularized logistic regression on hand-built EEG features. It was developed on the retired UEA conversion.

The original Phase 1 metrics are invalid-source history. A separate corrected-data reevaluation of the terminal-feature variant reached 78.58% mean OOF balanced accuracy and is stored under `../../results/archived_terminal_logistic_official_matlab/`.

This package is not the selected model and is not imported by active code.
