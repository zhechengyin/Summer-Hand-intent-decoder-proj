# Historical project record

- `EXPERIMENT_LOG.md` is the append-only chronological record.
- `HISTORICAL_SUMMARY.md` preserves the former cumulative summary, including
  superseded and sometimes contradictory historical conclusions.
- `ARCHIVE_RETIREMENT.md` maps every retired experiment/code family to its
  historical outcome and explains why the implementation was deleted.

Neither file is the current source of truth. Use `../STATUS.md` for that.
