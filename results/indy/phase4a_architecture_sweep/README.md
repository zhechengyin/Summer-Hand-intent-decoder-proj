# Phase 4a architecture sweep

Completed on 2026-07-27. This folder contains the architecture-only,
pre-January Optuna study. The frozen baseline checkpoint was checksum-protected,
January was not loaded and no model weight was saved.

The highest selection score came from a 48-TCN-filter/48-GRU-hidden candidate
with the baseline's four blocks, kernel size 3 and one GRU layer. It uses
45,266 parameters instead of 78,786, but its average R² advantage was very
small and its worst-session R² was lower. It is therefore a candidate for
multi-seed non-inferiority confirmation, not the active model.

Files:

- `phase4a_architecture_sweep_metrics.json`: complete protocol, trials and
  baseline-versus-candidate post-analysis;
- `phase4a_architecture_sweep_trials.csv`: all 30 Optuna trial records;
- `phase4a_architecture_sweep_unique_architectures.csv`: duplicates collapsed
  into 18 auditable architectures;
- `phase4a_baseline_vs_candidate_sessions.csv`: paired R² for all 33 held
  sessions;
- `phase4a_architecture_sweep_figure.png`: unique-architecture,
  aggregate/month and paired-session comparisons;
- `phase4a_architecture_sweep.db`: resumable Optuna study;
- `.cache/`: disposable fold arrays generated by the runner.

The 12 identical records for the 48/48 candidate are deterministic duplicates,
not independent replications. The active checkpoint remains
`models/indy_32ch/64x64checkpoint.pt`.
