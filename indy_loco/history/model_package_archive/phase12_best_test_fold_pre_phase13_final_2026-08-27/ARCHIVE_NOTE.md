# Archived best-test-fold model package

This directory is a byte-preserving archive of the 12 active packages that
existed immediately before the Phase-13 Round-3 final checkpoint promotion on
2026-08-27. It includes the old best-test-fold checkpoints, manifests, six
Phase-12 PC `.memlib` files, model/runtime code, and package builder.

These files use the old 60-second/best-fold deployment protocol and are not
compatible with the active seven-minute Phase-13 checkpoints. They remain only
for provenance and rollback. Do not use their R² values, memlibs, or generated
artifact assumptions as the final paper or CubeAI state.
