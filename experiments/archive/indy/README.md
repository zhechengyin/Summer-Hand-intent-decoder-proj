# Archived Indy/Loco experiments

These numbered scripts document completed investigations through LOG-086. They
are not the supported deployment API. Shared code is being extracted to
`src/intent_decoder/`; compatibility imports remain so historical scripts can be
inspected and, when all raw data are present, rerun.

The historical `iter34_detector_cv.py` is not a final detector validation because
its threshold was selected post hoc, it used half-session observations, and its
October fold selected epochs on an October validation session.
