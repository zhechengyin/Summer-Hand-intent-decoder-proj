# Project Memory Index

This project keeps memory in two places:

- [project_memory/SUMMARY.md](project_memory/SUMMARY.md): stable project summary, current policy, result ledger, interpretation, and next steps.
- [project_memory/DAILY_LOG.md](project_memory/DAILY_LOG.md): dated engineering log of what was changed, tested, plotted, and concluded each day.

Rule: keep `SUMMARY.md` short and current. Append detailed experiment notes to
`DAILY_LOG.md` instead of rewriting history.
